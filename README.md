# 纯回收校验温馨提示弹窗

将原有吐司错误提示改为阻塞式温馨提示弹窗。

## 页面

- `index.html`：移动端弹窗评审入口。
- `popup.html`：668 × 1474 全尺寸弹窗原型，可直接截图交付。

## 交互

- 标题固定为“温馨提示”。
- 正文为“{对应报错提示}是否纯回收，纯回收不执行该校验，不参与换新活动。”
- 对应报错提示可通过 `popup.html?error=自定义报错文案` 替换。
- 主按钮为“纯回收不参与活动”。
- 右上角提供关闭按钮，支持 `Esc` 键关闭。
- 关闭后点击“重新查看弹窗”可恢复演示状态。

## 本地预览

```bash
python3 -m http.server 4173
```

访问 `http://127.0.0.1:4173/`。
